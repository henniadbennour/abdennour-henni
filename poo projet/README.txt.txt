## 📝 Project Description
This is a simple Library Management System implemented as a C# console application. It allows users to:
- Add books to the library
- Remove books
- Borrow and return books
- Search books by title or author
- List all available books

The project demonstrates basic Object-Oriented Programming (OOP) concepts.

---

## 🎯 Project Goals
- Practice C# OOP concepts (classes, inheritance, polymorphism, interfaces)
- Apply simple data management using lists
- Gain experience using Git/GitHub for version control

---

## 💡 Key Concepts Implemented
- **Inheritance & Polymorphism:** `BorrowableBook` inherits from `Book` and overrides methods.
- **Interfaces:** `ILibraryOperations` interface defines library functionalities.
- **Encapsulation:** Book attributes (Title, Author, ISBN) managed using properties.
- **Data Handling:** Uses a `List<Book>` to store and manage book data.
- **Console Interaction:** Simple text-based menu for user interaction.
